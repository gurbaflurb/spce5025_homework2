SPCE 5025 - Homework 2

Using Homework 1 as a base, and extending it to meet homework 2 requirements

Homework 1: https://github.com/gurbaflurb/spce5025_homework1

Takes in a provided set of vectors, one for the position, and one for the velocity of a satellite. This then calculates the following:

- a - Acceleration
- e - Eccentricity
- i - Inclination
- RAAN - Right Ascension of Ascending Node
- aop - Argument of Periapsis
- v - Velocities
- TP - Orbit Period
- r-sub-a - Apoapsis radii
- r-sub-p - Perigee radii


For this assignment, I've pre staged all the provided vectors into a single yaml file to streamline things. Thanks to IEEE 754, the values output by this are close to correct, but just off.
